# นโยบายการเบิกค่าใช้จ่าย (ฉบับย่อสำหรับอบรม)

บริษัท สยาม ฟู้ด เซอร์วิส (ข้อมูลจำลอง) — มีผลตั้งแต่ 1 ก.ค. 2569

## กฎหลัก

1. **ค่าอาหารรับรองลูกค้า** เบิกได้ไม่เกิน **2,000 บาทต่อครั้ง** หากเกินต้องมีการอนุมัติล่วงหน้าจากผู้จัดการแผนก (คอลัมน์ `approval` ต้องเป็น "อนุมัติแล้ว")
2. **ทุกรายการต้องมีใบเสร็จ** (คอลัมน์ `receipt_no` ต้องไม่ว่าง) ยกเว้นค่าโทรศัพท์แบบเหมาจ่าย
3. **ค่าเดินทางและค่าน้ำมันในวันเสาร์-อาทิตย์** ต้องมีคำสั่งให้ทำงานนอกเวลาแนบมาด้วย หากไม่มีถือว่าผิดนโยบาย
4. ค่าที่พักเบิกได้ไม่เกิน 2,500 บาทต่อคืน
5. ต้องส่งเบิกภายใน 30 วันนับจากวันที่เกิดรายการ

## ผลลัพธ์ที่ต้องการเมื่อให้ Claude ตรวจ

- ตารางรายการที่ผิดนโยบาย: วันที่ / พนักงาน / แผนก / หมวด / จำนวนเงิน / กฎข้อที่ผิด / ข้อเสนอแนะ
- สรุปยอดรวมและจำนวนรายการที่ผิดต่อแผนก
- ระบุระดับความรุนแรง: สูง (เกินวงเงินโดยไม่อนุมัติ) / กลาง (ไม่มีใบเสร็จ) / ต่ำ (อื่น ๆ)
