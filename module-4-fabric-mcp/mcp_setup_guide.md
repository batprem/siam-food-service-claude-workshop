# คู่มือเชื่อมต่อ MCP Connector (Microsoft Fabric) ใน Claude Desktop

> ผู้สอนจะแจก URL ของ connector ในห้องอบรม ในเอกสารนี้จะเขียนแทนด้วย `<URL จากผู้สอน>`
> ห้ามนำ URL ไปเผยแพร่ภายนอกห้องอบรม

## สิ่งที่ต้องมี

- Claude Desktop เวอร์ชันล่าสุด (Windows หรือ macOS) และล็อกอินด้วยบัญชีที่ผู้สอนกำหนด
- เชื่อมต่ออินเทอร์เน็ต / Wi-Fi ของห้องอบรม
- URL ของ connector จากผู้สอน

## ขั้นตอนการเพิ่ม Connector

1. เปิด Claude Desktop แล้วคลิกไอคอนโปรไฟล์มุมล่างซ้าย เลือก **Settings**
2. ไปที่แท็บ **Connectors**
3. เลื่อนลงล่างสุด คลิก **Add custom connector**
4. กรอกข้อมูล
   - **Name:** `Siam Food Fabric` (ตั้งชื่ออะไรก็ได้ที่จำง่าย)
   - **Remote MCP server URL:** วาง `<URL จากผู้สอน>`
5. คลิก **Add** แล้วรอ 5–10 วินาที
6. ถ้าระบบเด้งหน้าล็อกอิน ให้ล็อกอินด้วยบัญชีที่ผู้สอนแจ้ง แล้วกด **Allow**
7. กลับมาที่หน้าแชต คลิกปุ่ม **+** หรือไอคอนเครื่องมือ ตรวจว่า connector ขึ้นสถานะ **Connected** และมีเครื่องมือ (tools) ปรากฏ

## ทดสอบว่าใช้งานได้

พิมพ์ในแชตว่า

```
มีตารางอะไรบ้างในฐานข้อมูลที่เชื่อมอยู่ อธิบายสั้น ๆ ทีละตาราง
```

ถ้า Claude ตอบชื่อตารางกลับมาได้ แปลว่าเชื่อมต่อสำเร็จ จากนั้นลองคำถามใน `sample_questions.md`

## แนวทางถามข้อมูลให้ได้ผลดี

- ระบุช่วงเวลาให้ชัด เช่น "เดือนสิงหาคม 2569" แทน "เดือนที่แล้ว"
- ระบุหน่วยที่ต้องการ เช่น "เป็นบาท ปัดเป็นพัน"
- ขอให้แสดง "ตารางที่ใช้และเงื่อนไขที่กรอง" เพื่อตรวจสอบได้
- ถ้าผลลัพธ์ดูแปลก ให้ถามกลับว่า "ตัวเลขนี้มาจากคอลัมน์ไหน กรองอย่างไร"

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---|---|---|
| กด Add แล้วขึ้น "Unable to connect" | พิมพ์ URL ผิด / เว้นวรรคท้าย / ไม่ได้ต่อเน็ต | คัดลอก URL ใหม่ทั้งบรรทัด ตรวจว่าขึ้นต้นด้วย `https://` |
| เชื่อมแล้วแต่ไม่มี tools ปรากฏ | ยังไม่ได้เปิดใช้ใน chat หรือยังไม่ล็อกอิน | ปิดแชตเดิม เปิดแชตใหม่ กดปุ่มเครื่องมือ เปิดสวิตช์ connector |
| ถามแล้ว Claude ตอบว่าไม่มีสิทธิ์ | บัญชียังไม่ได้รับสิทธิ์เข้าถึงข้อมูล | แจ้งผู้สอนพร้อมชื่อบัญชีที่ใช้ล็อกอิน |
| ตอบช้ามาก / timeout | คำถามกว้างเกิน ดึงข้อมูลเยอะ | จำกัดช่วงเวลาหรือขอ top 10 ก่อน |
| ตัวเลขไม่ตรงกับรายงานที่เคยเห็น | นิยามต่างกัน (เช่น รวม/ไม่รวม VAT) | ถามให้ Claude อธิบายเงื่อนไข แล้วระบุเงื่อนไขที่ต้องการใหม่ |
| ต้องการลบ connector | — | Settings → Connectors → คลิก ⋯ ข้างชื่อ → Remove |

## ข้อควรระวังด้านความปลอดภัย

- ข้อมูลในอบรมเป็น **ข้อมูลจำลอง** แต่ให้ปฏิบัติเหมือนข้อมูลจริง: ไม่ส่งภาพหน้าจอออกนอกองค์กร
- อย่าวาง URL ของ connector ลงในเอกสาร แชตกลุ่ม หรือ repo สาธารณะ
- เมื่อจบอบรม ให้ Remove connector ออกจาก Claude Desktop
