# Sales Visit Report

## เมื่อไหร่ใช้

- พนักงานขายแปะโน้ตสั้น ๆ หลังเข้าพบลูกค้า แล้วขอให้ "สรุปเป็นรายงาน"
- มีไฟล์ .txt / .docx ที่เป็นโน้ตการประชุมกับลูกค้า
- **ไม่ใช้เมื่อ** ผู้ใช้ต้องการวิเคราะห์ยอดขายจากตัวเลข (ใช้การวิเคราะห์ข้อมูลแทน)

## ขั้นตอน

1. ดึงข้อมูลหลักจากโน้ต: ชื่อลูกค้า, ประเภท (ร้านอาหาร/โรงแรม/เคเทอริ่ง), วันที่, ผู้ติดต่อ, สินค้าที่พูดถึง
2. ถ้าไม่มีวันที่หรือชื่อลูกค้า ให้ถามก่อน 1 ครั้ง
3. แยก "สิ่งที่ลูกค้าต้องการ" ออกจาก "สิ่งที่เราเสนอ"
4. ระบุโอกาสขาย (SKU + ปริมาณโดยประมาณ + มูลค่าถ้าประเมินได้) และอุปสรรค (ราคา, คู่แข่ง, การส่ง)
5. สรุป Next action พร้อมผู้รับผิดชอบและกำหนดวัน

## รูปแบบผลลัพธ์

```
# รายงานเยี่ยมลูกค้า: <ชื่อลูกค้า>
วันที่: | ผู้เข้าพบ: | ผู้ติดต่อฝั่งลูกค้า:

## สรุป 3 บรรทัด
## ความต้องการของลูกค้า
## โอกาสขาย
| SKU | สินค้า | ปริมาณ/สัปดาห์ | มูลค่าประมาณ | โอกาสปิด (สูง/กลาง/ต่ำ) |
## อุปสรรค / ข้อกังวล
## Next actions
| งาน | ผู้รับผิดชอบ | กำหนด |
```

## ตัวอย่าง

**ข้อมูลเข้า:** "ไปร้านชาบูหม้อทอง เจอคุณต้น เจ้าของ อยากได้หมูสามชั้นแช่แข็ง 40 กก./สัปดาห์ ตอนนี้ซื้อจากเจ้าอื่นถูกกว่าเรา 5 บาท ขอใบเสนอราคาภายในศุกร์"

**ผลลัพธ์:** รายงานตามรูปแบบข้างต้น ระบุ FZ-1502 ปริมาณ 40 กก./สัปดาห์ อุปสรรคเรื่องราคา และ next action "ส่งใบเสนอราคาภายในวันศุกร์"

## ข้อควรระวัง

- ไม่แต่งตัวเลขที่ลูกค้าไม่ได้พูด
- ใช้ชื่อ SKU จากรายการสินค้าบริษัทถ้าพอระบุได้ ถ้าไม่แน่ใจให้ใส่ "(ยืนยัน SKU)"
