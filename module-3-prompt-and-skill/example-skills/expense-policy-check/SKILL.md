# Expense Policy Check

## เมื่อไหร่ใช้

- Finance/HR แนบไฟล์รายงานค่าใช้จ่ายรายเดือน แล้วขอให้ตรวจ
- ผู้ใช้ถามว่า "รายการไหนเบิกไม่ได้บ้าง"
- **ไม่ใช้เมื่อ** ต้องการทำงบประมาณหรือพยากรณ์ค่าใช้จ่าย

## ขั้นตอน

1. อ่านไฟล์นโยบาย (expense_policy.md) ถ้าไม่มีให้ถามผู้ใช้ว่านโยบายคืออะไร
2. อ่านไฟล์ค่าใช้จ่าย ตรวจว่ามีคอลัมน์ date, employee, department, category, amount, receipt_no, approval
3. ตรวจทีละกฎ:
   - ค่าอาหารรับรอง > 2,000 บาท และ approval ไม่ใช่ "อนุมัติแล้ว"
   - receipt_no ว่าง (ยกเว้นค่าโทรศัพท์)
   - วันที่เป็นเสาร์/อาทิตย์ และหมวดเป็นค่าเดินทาง/ค่าน้ำมัน
   - ค่าที่พัก > 2,500 บาท
4. ให้ระดับความรุนแรง: สูง / กลาง / ต่ำ ตามนโยบาย
5. สรุปยอดรวมต่อแผนก และเสนอข้อความแจ้งพนักงาน

## รูปแบบผลลัพธ์

```
# ผลตรวจค่าใช้จ่าย <เดือน>
สรุป: ตรวจ N รายการ พบผิดนโยบาย M รายการ รวม X บาท

| วันที่ | พนักงาน | แผนก | หมวด | จำนวน | กฎที่ผิด | ระดับ | ข้อเสนอ |
|---|---|---|---|---|---|---|---|

## สรุปต่อแผนก
## ร่างข้อความแจ้งพนักงาน (สุภาพ สั้น)
```

## ตัวอย่าง

**ข้อมูลเข้า:** expense_report_aug.xlsx + expense_policy.md

**ผลลัพธ์:** ตารางรายการผิดนโยบาย 5 รายการ เช่น ค่าอาหาร 3,200 บาทไม่มีอนุมัติ (สูง), ค่าเดินทางไม่มีใบเสร็จ (กลาง), เดินทางวันเสาร์ (ต่ำ)

## ข้อควรระวัง

- วันเสาร์-อาทิตย์ให้คำนวณจากวันที่จริง อย่าเดา
- แสดงจำนวนเงินเป็นตัวเลขมีลูกน้ำ เช่น 2,650
