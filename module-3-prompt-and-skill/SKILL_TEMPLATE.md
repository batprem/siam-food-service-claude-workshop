# ชื่อ Skill

## เมื่อไหร่ใช้

- ผู้ใช้ขอ ... (เขียนคำที่ผู้ใช้มักพิมพ์ เช่น "สรุปการเยี่ยมลูกค้า", "ตรวจค่าใช้จ่าย")
- มีไฟล์ประเภท ... แนบมา
- **ไม่ใช้เมื่อ** ... (ระบุขอบเขตที่ไม่ควรใช้)

## ขั้นตอน

1. อ่านข้อมูลนำเข้า: ระบุว่าต้องการอะไรบ้าง (ไฟล์ / ข้อความ / ตัวเลข)
2. ถ้าข้อมูลไม่ครบ ให้ถามคำถามเหล่านี้ก่อน: ...
3. วิเคราะห์ตามเกณฑ์: ...
4. ตรวจสอบตัวเอง: ...
5. สร้างผลลัพธ์ตามรูปแบบด้านล่าง

## รูปแบบผลลัพธ์

```
## หัวข้อ
- สรุป 1 บรรทัด
| คอลัมน์ 1 | คอลัมน์ 2 |
|---|---|
## สิ่งที่ต้องทำต่อ
```

## ตัวอย่าง

**ข้อมูลเข้า:** ...

**ผลลัพธ์ที่คาดหวัง:** ...

## ข้อควรระวัง

- ใช้ภาษาไทยเป็นหลัก ศัพท์เทคนิคใช้อังกฤษได้
- ห้ามเดาตัวเลขที่ไม่มีในข้อมูล ให้เขียนว่า "ไม่มีข้อมูล"
